# V0.2 验收记录

日期：2026-09-20。范围：单用户本机平台，Windows、Python 3.12、Node 24、Microsoft Edge。按用户澄清，确定性 Python 工具 Agent 为核心验收对象；真实模型 Agent 兼容性单列 pending，不以付费模型为前置条件。

## 实现与检查

- CLI 创建任务／执行并返回网页链接，启动子进程、转发输出和退出码。SDK 显式包装同步／异步工具，保留返回、异常与嵌套关联。
- SQLite v1→v2 迁移先备份，保留历史任务。接收批次原子写入，事件 ID 与生产者序号去重，重复内容冲突拒绝，跨 Run 隔离。
- 现场事件有不可变接收记录及证据哈希。精确 ID 关联缺返回、乱序及歧义；未匹配调用保持可见。
- SSE 使用持久化变化游标；网页重连、刷新、暂停跟随和最新页均已验证。现场／历史来源、执行、验收与采集完整性分别显示。
- 实际确定性 Agent 执行文件写入和独立 Python 断言，成功和失败路径均验收；失败路径特意正常退出，确认 completed 与 failed outcome 能并存。
- 实际 TCP 服务关闭后，outbox 保留未确认数据；重启服务和 CLI resume 后补齐，SSE 从旧游标恢复。
- 真实进程测试覆盖非零退出、Windows Ctrl+Break、CLI 硬杀后的失联。硬杀保持最后已知执行状态与未知验收，不伪造失败或成功。
- 会话凭据、过期、来源限制、字段与大小限制、spool 超限告警和常见凭据脱敏均有自动检查。

自动化入口：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/integration -q
cd apps/web
npm run build
npx playwright test
```

浏览器测试依赖按 README 启动的独立 8001 测试服务；使用合成数据，不改主库。后端／SDK／真实进程检查共 40 项；浏览器核心检查共 4 项。历史私有 SymPy 浏览器检查默认跳过，先前 V0.1 的独立验收仍有效。

性能样本：100 条合成协议事件从生成时间、HTTP 接收到 SSE 更新及 Edge DOM 首次出现，初次调优后 p95=589 ms，满足本机演示 ≤2 秒目标。该测量不包含模型时间或 Collector outbox 延迟，不代表高并发保证；最新明细保存在被忽略的 `.local/live-latency.json`。

## 调试发现

- Windows 无限期 child.wait 会延迟 Python 信号处理，最初中断测试失败。改为有界轮询等待，同时注册 SIGBREAK，实际进程中断复测通过。
- SSE 空闲轮询最初为 2 秒，100 条浏览器样本 p95=2013 ms，未达目标。改为 0.5 秒轮询后复测通过，未放宽阈值。
- 现场页面中的历史模型／验收文案已区分；桌面与 390px 窄屏截图检查无横向溢出。

## 限制与 pending

- 未调用任何付费模型，未加载 analyst/HGT/repair；诊断引擎显示未接入。真实 LLM Agent 兼容性 **pending**，见 [接入说明](v0.2-agent-integration.md)。
- 自动采集任意框架、token 流、自动重试和远程多用户部署不属于本版。
- 单服务 SQLite，每轮最多 20,000 事件；Correlator 在批次提交时重建该 Run 的精确关联，尚未为长轨迹和高并发优化。
- 首版会话 24 小时有效。超过有效期的补传、凭据续期和长期 spool 管理未实现。
- complete 仅表示声明范围内事件到齐；字段截断有标记，不表示无损保存原程序的所有内部行为。脱敏不能覆盖任意自定义秘密格式。
- 普通权限运行，不提供进程沙箱；CLI 只执行用户提供的本机命令。后端无命令执行接口，服务仅绑定回环地址。
- API 依赖目前有两条 Starlette/anyio 弃用警告，不影响本次检查；依赖一致性检查通过。
