## 组件职责

| 组件 | 当前职责 |
| --- | --- |
| `RunWorkspace` | 延续事件读取、SSE count 增量、分页、筛选、跟随、选择、证据反向定位；接入共享时间窗，不改业务控制 |
| `useTimelineView` | 仅计算本页/整轮线性窗口，1–128×（受 1ms 最小窗口约束）缩放、半窗平移、fit、选中步骤聚焦 |
| `TimelineNavigation` | 前后移动、缩放倍数、缩小/放大、适配、聚焦；双击行也聚焦 |
| `TimelineRuler` + `TimelineGrid` | sticky 刻度与覆盖整段列表的垂直参考线；与所有行共享相同列宽/padding/gap |
| `TimelineMark` | 可信区间 bar、单时刻 diamond、缺失时间空值、时间窗之外方向提示；裁剪边使用虚线，失败真实终点红色 |
| `TraceBranch` + `TraceType` | 真实 parent 分支线、折叠，SPAN/CALL/RETURN/LLM/LOG/CHECK/EVENT/AGENT 类型标签 |

主列表改为单行：位置、真实层级、类型、名称、引用/结果图标、Timeline、Duration。删除独立状态列和重复第二行类型说明（类型保留为可访问文本），原始记录入口留在右侧。移除每行浅灰轨道与重复每行网格线。

## 数据规则

1. 同名 tool_call/tool_return 有唯一 `correlation_id`、调用在返回之前且 parent 不冲突，才形成 UI 逻辑 SPAN。调用和返回的事件 ID/evidence_id/行号仍独立保留。
2. 逻辑 SPAN 只有两端带时区时间有效、end > start、与来源 duration_ms 无显著冲突时才画区间；其余仍只有时间点，来源 duration 文本原样保留。不用时间邻近配对。
3. stdout/stderr、OUTCOME_EVIDENCE、RUN_START/RUN_END、只有响应记录的 LLM、无关联/重复关联的调用与返回等仍是普通 Event 的时间点。无时间不画 marker；无有效时间范围退回顺序视图。
4. 唯一可解析、无循环/自环的实际 source parent 才画层级。筛选时平铺匹配结果。不制造 TRACE 根区间，不把所有日志归到相邻 Tool。
5. 时间条位置/长度线性映射源时间，刻度始终相对 Run 来源起点；缩放只改变窗口。极短区间保留最小可点击/可见的像素标记，tooltip 和数值展示真实区间；不将其放大为任意百分比。
6. selected 行和 bar 同时加强；失败区间保持红色，引用用轻量 link 图标。普通事件 marker 不表示 duration，选中错误也不改变独立验收或诊断状态。

## 已实现与暂缺

- 已实现：共享坐标、真实分支、point/bar、hover/selected/failed/referenced、既有右侧联动、page/run fit、按钮 zoom/pan、双击/按钮 focus、时间窗外提示。
- 数据不足：大部分真实导入事件没有可靠 parent，所以仍平铺；LLM 缺少独立 start/end，不能画 GENERATION 区间；运行中的未返回调用只画开始点，不能臆测当前持续时长。需要未来提供稳定 span_id/parent_id、span kind、可靠双端时间和时钟域，才能展示更完整的 Agent/LLM 树。
- 尚未移植的交互（范围控制，与数据不足区别）：滚轮/捏合、鼠标拖动平移、框选窗口、完整 trace 全节点虚拟画布。保留现有 50 行分页，fit 适配所选本页/整轮时间范围，不声称等同 Langfuse 全节点双轴 fit。
