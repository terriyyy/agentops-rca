## 已实现

- SQLite v3 持久化作业；从 v2 升级先保存 `.v2-backup.sqlite3`，原始轨迹与历史诊断不覆盖。
- 已结束的完整执行生成独立不可变 JSON 输入快照；模型引用通过平台事件 ID 回到原始证据。
- 一个独立 CPU worker 同时运行一个作业，120 秒超时，支持取消、服务关闭／重启中断；晚到输出不能发布为成功。
- 配置与模型加载检查，API 不接收命令、源码路径或权重路径；源码、manifest、权重在每次推理前重新核验 SHA-256。
- 真实 AgentTether unitizer、HGT bundle 与层次图构造；权重已加载成功。模型依赖独立于平台 Python。
- 页面可触发定位、看状态、取消、检查输入快照／算法与权重版本、追溯事件证据；新报告与历史报告分别标明来源。

## 使用

当前机器已完成模型配置。运行 `scripts/start.ps1`，进入一次已完成执行的“诊断报告”，点击“运行 HGT 定位”。“运行环境”可看到 `HGT 可用 · 完整 RCA 未启用`。已有报告可在不安装算法环境时查看。

新机器先安装平台，再单独配置可信算法环境：

```powershell
py -3.12 -m venv .local/diagnosis-venv
.local/diagnosis-venv/Scripts/python.exe -m pip install -r apps/api/diagnosis-requirements.lock
.venv/Scripts/python.exe scripts/configure-diagnosis.py `
  --python .local/diagnosis-venv/Scripts/python.exe `
  --source "<包含 agent_tether 包的源码根目录>" `
  --bundle "<包含 manifest.json 和真实 hgt_normal_model.pt 的目录>" `
  --expected-weight-sha256 "<从可信发布者独立确认的 SHA-256>"
```

脚本在真正反序列化权重前检查给定哈希；不要使用 Git LFS 指针代替真实权重。配置、模型、作业日志均留在 Git 忽略目录。重新配置时先结束当前诊断作业。服务使用一个 Uvicorn worker；不要让多个服务同时写同一个数据库。

验收命令：

```powershell
.venv/Scripts/python.exe -m pytest tests/integration -q
cd apps/web
npm run build
# 另开终端，设置 AGENTOPS_DB 为独立测试数据库后启动 8001 端口
npx playwright test
```

浏览器 HGT 检查需要已验证的本机模型，未配置则明确 skip；其他页面测试仍运行。协议单元测试使用标记为 synthetic 的 worker 输出，不冒充真实推理。

## 能力与输入边界

- `GET /api/diagnosis/capabilities` 返回 HGT 与 analyst 两种能力。`ready` 表示已通过该配置的加载检查；`degraded` 表示仅可离线定位，完整 RCA 不可用。文件被外部替换后，下一次 worker 会拒绝哈希不一致，需重新配置校验。
- `POST /api/runs/{run_id}/diagnosis-jobs` 使用 `request_id` 幂等提交；同一请求不会重复创建。`GET` 同路径列出作业，`POST /api/diagnosis-jobs/{job_id}/cancel` 取消。
- 报告保存输入快照哈希、源码树／权重／manifest 哈希、依赖版本、适配器版本与证据 ID。报告模型状态不会修改任务验收结果。
- 当前只接受无歧义串行调用，最多 5,000 事件／500 工具转换；并行或嵌套重叠、缺调用／返回、乱序、重复关联、未知执行结束、现场采集不完整均拒绝。
- 状态适配以平台归一化失败优先规则为准，记录调整项；失败状态与退出码 0 冲突会拒绝，避免原 unitizer 将其转成成功。
- 显式 verification、OUTCOME_EVIDENCE 与 RUN_END 不输入定位模型，验收仍独立保留。通用日志可能含接入方自行输出的答案，不能据此声称完成严格防泄漏实验。
- 使用未修改的叶模块，绕开上游包初始化的循环导入；并非运行完整 `generate_report`／RecoveryEngine。Python socket 出站连接被阻断，环境变量采用白名单；这是可信本地代码的进程隔离，不是容器或恶意代码沙箱。
- 模型分数表示异常偏离，不能称为根因概率或已证实因果；新工具／新任务分布上的准确率、资源上限和大规模输入尚未评测。
