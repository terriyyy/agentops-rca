# RCA 模型连接与凭据管理

进入运行环境 → 管理模型连接，或 Run 的原因分析区 → 管理连接。页面地址 `/settings/models`。

## 当前实现范围

一个本地工作区默认连接，包含连接名称、API Base URL、模型 ID、API Key 和输出上限参数。当前支持 OpenAI-compatible **Chat Completions**，地址由用户配置，后端追加 `/chat/completions`。不是任意协议模型适配器；不支持原生 Anthropic Messages、OpenAI Responses 或自动代理路由。支持 HTTPS，自定义本机地址可用 HTTP；不能把完整请求路径、凭据或查询参数写进 Base URL。

这里配置的是 RCA 分析模型；被监控 Agent 自身的模型、密钥仍由接入方管理。单次输出上限 2,500 token，可选择 `max_tokens` / `max_completion_tokens`；服务商账户须授权使用填写的模型。保存不进行网络测试，不调用模型或本机定位。最近调用成功/失败只属于同一份连接版本，不保证未来服务可用。

## 使用流程

1. 添加连接并填写自己的 API Key。编辑时留空保留已保存密钥；更换服务地址必须重新提供对应服务的密钥。
2. 在已结束且可诊断的 Run 中，手动定位异常步骤。
3. 查看发送预览，核对模型、服务地址、完整请求体（系统指令、候选证据与输出限制）。认证头不显示密钥。
4. 人工确认后仅发起一次模型请求；不自动重试或换模型。服务可能收费，取消已发送调用仍可能计费。
5. 返回的原因是待验证假设，不能覆盖独立任务检查结果；建议检查并未被平台自动执行。

地址、名称、模型、密钥或请求参数改变时连接版本更新，旧发送预览不能再次提交。连接保存使用版本校验，防止两个页面相互覆盖。已有调用使用确认时的不可变配置；编辑或删除连接不会撤回已发送调用。

## 凭据保存与删除

默认目录 `.local/rca-credentials/` 已被 Git 忽略。API Key 使用 Fernet 加密；Windows 中用于文件加密的密钥另受当前 Windows 用户 DPAPI 保护，其他系统采用仅所有者可读写的密钥/配置文件与目录权限。不是云 KMS 或账户隔离：拥有同一 OS 用户权限或主机管理权限的人仍可能访问凭据。不要将该目录、`.env`、模型权重或运行数据库打包交接。更换 Windows 用户或遗失加密密钥后，需重新配置连接。

接口只返回连接元数据与是否配置，不回传密钥。浏览器不使用 localStorage/sessionStorage 存储 API Key；报告、输入快照、命令行参数和子进程环境不保存该凭据，作业通过标准输入获取一次性内存凭据。已有遥测或上传原件中的敏感内容需要单独审查，不代表所有历史原始证据都已脱敏。

已有 `.env` 配置保留兼容，页面明确标注“本机 .env”。用户保存后才接管到加密存储，不自动修改原文件。删除连接会移除其加密凭据并写入停用记录，**不会回退读取旧 `.env` 密钥**；原 `.env` 文件不自动删除。若加密存储损坏，页面提供显式删除后重新配置入口。

## 部署边界与开发隔离

当前服务绑定本机、使用本地工作区，没有账户级私人凭据隔离；共同部署到服务器前必须补账户、权限、工作区归属和端点访问策略。团队共享连接也需明确管理员及计费归属。不要直接对公网暴露本地设置 API。该功能不承诺防御具有主机访问权限的攻击者。

正常本地服务使用仓库 `.env` 作为旧配置来源。设置 `AGENTOPS_DB` 或通过 `create_app(db_path=...)` 使用隔离数据库时，凭据位于数据库旁的 `rca-credentials/<数据库文件主名>/`，默认定位配置为 `diagnosis-config-<数据库文件主名>.json`；即使数据库同在 `.local`，也不会共用生产凭据或定位配置，且不读取仓库 `.env`。可显式设置 `AGENTOPS_MODEL_SETTINGS_DIR` 与 `AGENTOPS_DIAGNOSIS_CONFIG`；测试需要旧环境时用 `legacy_env_file` 注入测试文件。

## 信息展示

普通调查路径展示异常步骤定位、待验证原因、可追溯证据与任务检查。报告来源、算法版本、HGT、AgentTether、校验 SHA-256、结构图和原始 JSON 保留在运行资料的高级信息内，默认折叠。历史报告模型以生成时的 provenance 为准，不用当前连接覆盖历史记录。
