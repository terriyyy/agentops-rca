# V0.3 analyst RCA 接入验收

2026-09-26：AgentTether 的 HGT + `LLMRecoveryAnalyst` 接入已完成。它生成**待验证的根因假设**；未执行自动修复，也没有把模型建议写成独立任务验收。此适配流程调用原 analyst 的解析和 `RecoveryPlan` 结构，但不声称逐字段复现上游 `generate_report`／`RecoveryEngine` 全管线。

## 使用

在已结束且采集完整的 Run 的“诊断报告”页：先点“运行 HGT 定位”；成功后点“查看 RCA 发送内容”，检查脱敏片段、模型和字节数，再点“确认并运行 RCA”。第二步才会向 ChatAnywhere 发出请求。页面可取消本机作业；若请求已送达服务商，仍可能计费。刷新页面后作业与报告仍在。

本机 `.env` 已配置并被 Git 忽略；新环境可复制根目录的 `.env.example`，自行填写密钥。`.local/diagnosis-config.json` 和真实 HGT 权重仍须按 [离线诊断说明](v0.3-validation.md) 配置。启动命令仍是 `scripts/start.ps1`。不在聊天、截图、命令行参数、数据库报告或 Git 中展示密钥。

## 实现与数据边界

- `GET /api/runs/{run_id}/analyst-preview` 读取同快照的真实 HGT 报告，返回最多 12 个选中转换的脱敏预览、模型名、大小及哈希；最多 24 KB。旧格式 HGT 报告需重新运行一次定位。快照不完整、无候选、证据 ID 无法映射时拒绝发送。
- `POST /api/runs/{run_id}/analyst-jobs` 需要 `request_id`、预览哈希与 HGT 报告 ID；服务端重新计算后才建立作业。提示内容存为本地 EvidenceRef；同一请求幂等，服务重启不会自动重发。
- 离线 HGT worker 保持出站网络阻断。analyst 子进程只从根目录 `.env` 读取 Key；服务地址限定为 `https://api.chatanywhere.tech/v1`，禁止重定向、无自动重试，单次输出上限 2500 token，HTTP 超时 45 秒、作业超时 120 秒。密钥不序列化到作业、结果或子进程参数。
- 平台复用原 `LLMRecoveryAnalyst.analyze_to_plan()` 的 JSON 解析与计划生成；发送内容和传输参数由本地适配层限制。要求模型回传的转折点 ID 属于本次 HGT 候选；证据链中未知的 ID 显式标为 unresolved。缺 JSON、缺关键计划字段、错误 ID、401/403/429 或超时都不会发布成功报告。
- 报告存储输入快照、HGT 报告、实际发送的提示、算法/权重哈希、模型名与可用的 token 用量。`verification_suggestion` 是**建议运行的检查**，没有改变 Run 的 `outcome_status`。
- 脱敏覆盖常见 Bearer、`sk-`、key/token/password 等字段。任意自由文本仍可能含无法自动识别的敏感内容，因此发送前预览是必要的人工检查。

## 验收结果

- 使用本机真实 HGT 权重，对一条明确失败的合成工具轨迹生成候选。首轮 analyst 请求因回复未满足结构化要求而失败，未发布报告；提高单次输出上限后，下一次**手动**调用成功。没有自动重试。
- 最终真实合成案例返回结构化根因假设；请求 `gpt-5.6-luna`，本次使用 801 个输入 token、613 个输出 token。两个原始事件引用均解析成功，发送内容哈希与持久化证据一致，任务验收仍为 `unknown`。这验证工程链路，不代表跨任务诊断准确率。
- 本地模拟传输验证原 analyst 的成功、非 JSON、403、429、无效转折点和单次请求；API 测试涵盖预览脱敏、哈希匹配、幂等、401、取消后不发布、历史/HGT 报告保留及 Outcome 不变。
- 后端集成测试 57 项、浏览器回归 6 项与前端生产构建通过；浏览器验证发送预览、手动触发参数、已完成报告、证据跳转及 390px 页面。真实 SymPy 私有样例页面测试按既有配置跳过。首轮浏览器标题定位器过宽以及一次验收命令传错 Run ID 已修正，最终全量重跑通过。

## 仍需后续工作

需要更多失败/成功配对案例和人工标注，评估转折点命中率、证据完整性、建议验证的可执行性及模型调用成本。真实模型 Agent 的采集兼容性、自动修复、自动重试和自动验收不在本版；本实现也不替代上游全部报告/恢复管线。单机 SQLite 与本地回环服务仍只面向单用户开发环境。
