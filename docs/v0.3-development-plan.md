# V0.3 实施计划

状态：2026-09-20 离线 HGT 阶段已验收；2026-09-26 analyst 接入也已完成，见 [续阶段验收](v0.3-analyst-validation.md)。以下实施条目保留当时的离线阶段规划语境。

1. 本机配置外部 AgentTether 源码、独立 Python 和权重目录；核对已确认 SHA256，记录实际依赖版本，不把第三方源码或权重纳入 Git。
2. 对已结束且采集完整的 Run 创建不可变快照，保留平台事件 ID 到源证据映射；历史报告保持不变。不读取持续变化的执行输入。
3. 隔离进程导入指定版本算法，禁用网络，调用原始 unitizer、HGT bundle 和图构造。已知 unitizer 不支持可靠的并行观察归属，首版拒绝并行／歧义／缺返回输入，不能静默伪造因果。
4. SQLite 持久化诊断作业和结果，支持幂等请求、超时／取消、重启后 interrupted；晚到结果不能覆盖取消状态。服务只调用服务器配置中的 Python／算法，API 不接收任意命令和路径。
5. 页面提供手动启动、状态、报告来源、快照／模型／算法版本和证据跳转。HGT 仅是异常定位，不将其分数显示为根因概率。
6. 实际加载已核对权重，对确定性失败执行做 HGT 推理；协议测试可用标记 fixture 的 worker 输出。完整 RCA analyst 需要用户提供授权环境，缺失时清楚显示 degraded／pending，不触发付费调用。

离线模式不运行 repair 或自动修改 Agent 文件。以 user-confirmed 的 V0.2 确定性工具 Agent 验证平台闭环，真实 LLM Agent 兼容性继续 pending。

离线阶段完成记录与限制见 [V0.3 验收说明](v0.3-validation.md)。后续 analyst 接入已完成；自动修复及真实模型 Agent 兼容性仍需另行推进。

Analyst 接入的实施与验收关口见 [V0.3 analyst RCA 续阶段计划](v0.3-analyst-development-plan.md)。
