# V0.1 实现与验收记录

## 已实现

- Python/FastAPI API + SQLite，原始附件、规范化记录和导入事务共同提交。
- 版本化导入清单；精确文件集合、文件／请求／事件数限制；UTF-8 校验与路径拒绝。
- 旧版 PROBE 和增强版报告适配；独立任务验收、运行状态、模型状态。
- 同一 Run 内 correlation_id 精确配对、父引用、重复／缺失关联告警；不猜测时间因果。
- 以事件 ID 或明确关联 ID 定位诊断证据；未解析引用可查看报告中的原始引用，不伪造事件跳转。
- React/TypeScript 工作台：任务列表、执行历程、轨迹搜索／分页、诊断、验收、运行概览、两轮对照、导入和本地能力页。
- 原始图的阶段节点概览及原始关系查看，阶段顺序不被画成推断的因果链。未实现可交互的大型 CTG 网络布局。
- 所有模型状态明确来源于历史报告；没有调用 LLM 或加载 HGT。

## 自动化验证

- 后端21项检查：正常导入、重复导入幂等、内容冲突、全包回滚、跨轮 ID 隔离、稳定分页、缺返回／重复键、缺报告／验收、冲突结果、数据库重启、来源隔离、路径拒绝、请求／文件限制、异常编码、未知 ID、并发导入、原始 BOM/CRLF 哈希保持、非零退出码冲突、NaN拒绝，以及畸形展示字段的事务拒绝。
- 前端 TypeScript 校验和 Vite 构建通过，依赖由 package-lock.json 固定。
- Edge/Playwright 浏览器测试覆盖真实 HTTP 上传、任务对照、诊断证据、验收证据、事件搜索、错误提示和窄屏不溢出；公开夹具为人工合成并显式标记。
- 另外通过本机真实 SymPy 数据的浏览器检查：两轮数量／验收、诊断引用跳转及事件翻页；真实数据测试需显式设置 E2E_REAL 和 E2E_URL，默认不会要求测试者具有私有实验数据。
- 使用本地字体资产，页面运行无需访问外部字体服务。

测试环境为 Python3.12、Node24、Windows/Edge。后端测试出现来自 Starlette/httpx/anyio 的弃用提示，但检查通过；这是依赖内部迁移提醒，不影响当前功能。Python依赖版本见 requirements.lock，安装命令见README。

## 有意保留的边界

- 仅单用户本地使用，没有远程身份认证；服务默认绑定127.0.0.1。
- 真实历史记录没有自动脱敏，导入前需由操作者确认内容；原件只进入本地数据库，不会自动提交或上传。
- 数据库当前没有删除／编辑历史记录的产品入口；避免首版将原始记录改写。备份主数据库时先停止服务。
- 仅按可核实的源 ID 关联。TU映射不完整、缺失返回、并行语义不确定时显示告警。
- 前端列表针对小规模研究工作区；事件已分页，任务列表尚未做服务器分页。
- 后续能力尚未实现。按 2026-09-20 调整后的路线，V0.2 为现场采集与实时监控，V0.3 为权重加载及实际诊断；自动修复重试与独立验收的自动编排留待后续。该调整不改变本次 V0.1 验收结果。
