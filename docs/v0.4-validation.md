## 已交付

- 首页优先提供本机 CLI 接入、明确标记的演示入口、运行中、需要处理和其他最近 Run。活动及需处理列表分别有界查询，不会因较新的完成记录挤掉仍在运行的 Run。
- 首页、Task Detail、Run Detail 使用同一只读诊断投影。已有报告而最新诊断作业失败时，既显示已有报告，也显示最新作业失败；不会误写成“尚未诊断”。
- Run Detail 沿执行事实、失败事实及原始证据、待验证根因假设、独立验收、关联运行连续阅读。完整轨迹、报告历史、原始资料与工程字段保留在深入核查。
- Task Detail 仅说明显式归组的多轮历史及前后结果变化；不从先后顺序推断修复因果。单轮导入直接进入 Run，多轮导入进入 Task。
- `origin` 与 `sample_kind` 分别标注。进程执行、任务验收、诊断作业/报告、采集完整性、网页连接分别显示；没有独立验收依据时保持未知。
- 付费 analyst RCA 仍需先离线 HGT、查看实际发送预览，并手动确认。V0.4 不新增自动调用或自动修复，也不增加 Investigation 实体。
